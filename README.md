# 🔔 학교 수업 종소리 알리미 (School Bell Notifier) v1.2

학교에서 수업 시작·종료·예비종·점심시간·조종례 시각에 맞춰 **내장 차임벨 소리 또는 직접 준비한 MP3/오디오 파일**을 자동으로 울려주는 Windows 데스크톱 프로그램입니다.

외부 음원 플레이어나 별도 패키지(`pip install`) 설치 없이, **Python 및 Windows 기본 내장 오디오 기능(MCI / winsound)만으로 즉시 실행**됩니다.

---

## ✨ 주요 기능

1. **⚡ 수업 시작 / 수업 종료 벨소리 한 번에 일괄 설정 (v1.2 신규)**
   - **상단 [🔔 시작/종료 벨소리 일괄 설정] 버튼**:
     - 팝업 창에서 **수업 시작 벨소리**와 **수업 종료(쉬는 시간) 벨소리**, 재생 시간을 각각 선택하고 **[🚀 선택한 벨소리 일괄 적용]**을 누르면 시간표의 모든 교시(예: 1~7교시 전체)에 한 번에 적용됩니다.
   - **우측 패널 빠른 적용 버튼**:
     - 원하는 벨소리(또는 MP3)를 고른 뒤 **`[🟢 모든 '수업 시작'에 현재 소리 적용]`** 또는 **`[🔴 모든 '수업 종료'에 현재 소리 적용]`**을 누르면 현재 선택된 음원이 해당 카테고리 전체에 즉시 일괄 적용됩니다.
   - 교시마다 하나씩 찾아다니며 바꿀 필요가 전혀 없습니다!

2. **🎵 내 MP3 / 오디오 파일 직접 등록 & 재생**
   - 학교 교가, 클래식 명곡, 팝송, 안내 음성 등 **원하는 MP3 / WAV / WMA / M4A 파일**을 손쉽게 등록할 수 있습니다.
   - **[➕ 내 MP3 추가]** 버튼을 눌러 내 PC의 오디오 파일을 선택하면 프로그램 전용 폴더(`custom_sounds/`)로 자동 복사 및 등록됩니다.
   - **[📁 음원 폴더 열기]** 버튼을 눌러 탐색기에서 MP3 파일들을 직접 복사해 넣고 **[🔄 새로고침]**만 눌러도 자동 감지됩니다.
   - **재생 시간 제한 기능**: 3분짜리 긴 노래라도 수업 시작용으로 `10초`, `15초`, `20초`, `30초`, `1분` 등 원하는 길이만큼만 울리고 자동으로 멈추도록 설정할 수 있습니다.

3. **🔔 6가지 고품질 내장 학교 차임벨 (자체 물리 합성 엔진)**
   - 별도 MP3 파일이 없어도 즉시 사용할 수 있는 6가지 표준 학교 종소리를 기본 제공합니다.
   - **웨스트민스터 차임벨 (기본 학교종)**: 가장 친숙한 표준 딩동댕동 차임벨
   - **수업 시작 차임**: 산뜻한 상행 화음 차임벨
   - **수업 종료 / 쉬는 시간 차임**: 편안한 하행 화음 차임벨
   - **예비종 (짧은 딩동댕동 4음)**: 수업 시작 1~2분 전 착석 유도용 차임벨
   - **점심시간 멜로디**: 밝고 경쾌한 점심시간 알림 차임벨
   - **학교종이 땡땡땡**: 전통적인 오르골 스타일 멜로디

4. **초·중·고 표준 시간표 프리셋 & ⚡ 맞춤 자동 생성기**
   - **초등학교 표준** (40분 수업 / 10분 휴식 / 6교시)
   - **중학교 표준** (45분 수업 / 10분 휴식 / 7교시)
   - **고등학교 표준** (50분 수업 / 10분 휴식 / 7교시 + 2분 전 예비종)
   - **단축수업 표준** (35분 수업 / 10분 휴식 / 6교시)
   - 1교시 시작 시각, 수업/휴식 시간만 입력하면 하루 전체 타종표를 자동 완성해 주는 맞춤 생성기를 지원합니다.

5. **시간표 자유 편집 및 자동 저장**
   - 원하는 시각(`HH:MM`)에 타종 항목을 자유롭게 **추가 / 수정 / 삭제**할 수 있습니다.
   - 목록에서 항목을 **더블클릭**하면 개별 타종을 즉시 **켜기(ON) / 끄기(OFF)** 전환할 수 있습니다.
   - 모든 변경 사항은 `bell_config.json`에 즉시 자동 저장되며, **[💾 파일 저장]** / **[📂 파일 불러오기]**로 백업 및 복원이 가능합니다.

6. **실시간 대시보드 & 편의 기능**
   - 현재 시각, 다음 타종 시각 및 **남은 시간 카운트다운** 표시
   - **[🔔 지금 종 울리기]** 수동 타종 및 **[⏹ 소리 멈춤]** 즉시 정지
   - 슬라이더를 통한 실시간 음량 조절 및 주말(토·일) 자동 음소거

---

## 🚀 실행 방법

- **`학교종 실행.vbs`** 더블클릭 → 까만 콘솔 창 없이 프로그램 창만 깔끔하게 실행됩니다.
- 또는 터미널/명령 프롬프트에서:
  ```bash
  python app.py
  ```
- 오류나 로그를 확인하고 싶을 때는 **`실행(디버그).bat`** 파일을 실행하세요.
